Class ProjectileController

ProjectileController

Classdesc

Controlador MVC. Orquesta Modelo y Vistas sin conocer detalles de física ni de dibujo. Implementa ProjectileObserver (patrón Observer) para recibir la notificación de aterrizaje.

El bucle de animación usa un contador launchVersion para invalidar frames "fantasma" de animaciones anteriores sin necesitar cancelAnimationFrame.
