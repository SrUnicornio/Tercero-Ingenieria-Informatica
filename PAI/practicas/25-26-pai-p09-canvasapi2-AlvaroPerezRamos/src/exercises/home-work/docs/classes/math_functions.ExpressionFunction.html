Class ExpressionFunction

ExpressionFunction

Classdesc

Adaptador que convierte una expresión matemática en string en una MathFunction evaluable, usando mathjs como motor.

La expresión se compila una única vez en el constructor para maximizar el rendimiento durante el muestreo de la función.

Example

const f = new ExpressionFunction('sin(x)');
f.evaluate(Math.PI / 2); // 1
f.evaluate(Math.PI);     // ~0
