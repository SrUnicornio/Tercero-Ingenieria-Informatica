    Class LissajousController

    LissajousController

    Classdesc

    Controlador MVC. Orquesta modelo y vista sin conocer sus implementaciones internas.

    El bucle de animación usa requestAnimationFrame de forma continua. Cuando isPhaseAnimated es false, se sigue re-renderizando (el usuario puede cambiar parámetros manualmente) pero el modelo no avanza el desfase.

    Example

    const model = new LissajousModel();
    const view  = new LissajousView();
    new LissajousController(model, view);
