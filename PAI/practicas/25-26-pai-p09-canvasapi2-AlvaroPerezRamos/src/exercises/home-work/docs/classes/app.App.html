Class App

App

Classdesc

Fachada de la aplicación de representación de funciones.

Encapsula la inicialización y el ciclo de vida completo: cuadrícula → función. El cliente solo llama a start.

Example

const app = new App({
  canvasId:          'functionCanvas',
  inputId:           'functionInput',
  buttonId:          'renderButton',
  defaultExpression: 'sin(x)',
});
app.start();
