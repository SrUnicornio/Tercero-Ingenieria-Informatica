Class CartesianCoordinateSystem

CartesianCoordinateSystem

Classdesc

Fachada pública del sistema de coordenadas cartesianas. Proporciona un método simple para renderizar el sistema completo en un canvas, ocultando la complejidad interna de los renderizadores y el modelo. Permite personalizar la configuración del grid y los ejes al crear una instancia de esta clase.

  • new CartesianCoordinateSystem(canvasId, config?): CartesianCoordinateSystem

  • Parameters

    • canvasId: string

      ID del elemento canvas donde se renderizará el sistema de coordenadas.

    • Optional config: Partial<CartesianGridConfig>

      Configuración opcional para personalizar la apariencia del grid y los ejes. Si no se proporciona, se utilizará la configuración por defecto.

    Returns CartesianCoordinateSystem

    Description

    Inicializa el sistema de coordenadas cartesianas con el ID del canvas y una configuración opcional. Crea las instancias necesarias para manejar el canvas, el modelo geométrico y los renderizadores del grid y los ejes.

    Throws

    Error si el canvas no es válido o si no se puede obtener el contexto 2D.

    Method

    render

    Description

    Renderiza el sistema de coordenadas cartesianas completo en el canvas. Limpia el canvas antes de dibujar, y luego llama a los métodos de los renderizadores para dibujar el grid y los ejes. Este método es la única interfaz pública para renderizar el sistema, ocultando toda la complejidad interna.
