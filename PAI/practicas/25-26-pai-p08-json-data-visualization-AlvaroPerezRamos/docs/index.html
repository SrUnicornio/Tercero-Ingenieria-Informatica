    Práctica 8 — JSON Data Visualization

    Asignatura: Programación de Aplicaciones Interactivas
    Autor: Álvaro Pérez Ramos — alu0101574042@ull.edu.es
    Grado en Ingeniería Informática — Universidad de La Laguna

    Descripción

    Aplicación web que obtiene datos de población de los países europeos desde la API pública restcountries.com y los representa gráficamente en un diagrama de barras dibujado con la API Canvas de HTML5 y programado en TypeScript.

    El servidor Express actúa de proxy hacia restcountries.com para evitar restricciones CORS, y sirve la aplicación compilada junto con la documentación TypeDoc y el diagrama UML.

    Fuente de datos

    restcountries.com v3.1 — API pública, sin autenticación, devuelve nombre y población de todos los países europeos en formato JSON.

    Clases e interfaces

    Interfaces de datos externos (restcountries.com)

    • RCName — nombre común y oficial del país.
    • RCCountry — país con su nombre y población.
    • RCResponse — alias de RCCountry[], raíz de la respuesta.

    Modelo interno

    • TimeSeriesPoint — par año/valor de una serie temporal.
    • DataItem — elemento listo para renderizar: etiqueta, valor y serie.
    • DataAdapter — interfaz que define el contrato de transformación.

    Clases principales

    • RestCountriesAdapter — implementa DataAdapter, transforma RCCountry[] en DataItem[] ordenados por población descendente.
    • DataService — hace fetch al endpoint y delega la transformación.
    • BarChart — dibuja el gráfico completo en un canvas HTML5. Expone únicamente el método público draw(data).
    • AppController — coordina DataService y BarChart.

    Constantes de BarChart

    Constante Valor Descripción
    MILLION 1 000 000 Umbral M vs K en etiquetas de barras
    THOUSAND 1 000 Divisor para valores en miles

    X_LABEL_OFFSET 10 px Separación vertical etiquetas eje X
    X_LABEL_ROTATION π/4 rad Ángulo de rotación etiquetas eje X
    BAR_PADDING_RATIO 0.15 Proporción de padding lateral de barra
    BAR_VALUE_Y_OFFSET 4 px Separación valor encima de barra
    Y_LABEL_X_OFFSET 8 px Separación horizontal ticks eje Y
    Y_LABEL_Y_OFFSET 3 px Ajuste vertical ticks eje Y
    Y_AXIS_LABEL_OFFSET 55 px Distancia etiqueta título eje Y

    Patrones de diseño aplicados

    • Adapter — RestCountriesAdapter transforma la respuesta externa al modelo interno DataItem.
    • Service Layer — DataService encapsula la lógica de obtención de datos remotos.
    • Controller — AppController coordina servicio y vista (MVC simplificado).
    • DIP — DataService depende de la interfaz DataAdapter, no de la implementación concreta.
