Class AxisRenderer

AxisRenderer

Classdesc

Encargado de dibujar los ejes X e Y del sistema de coordenadas cartesianas. Dibuja las líneas de los ejes, las marcas (ticks) y las etiquetas con los valores correspondientes. Utiliza la configuración proporcionada para personalizar la apariencia de los ejes y las etiquetas.
