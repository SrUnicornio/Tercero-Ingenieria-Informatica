    Dibuja la gráfica de una función matemática sobre el sistema de coordenadas. Recorre cada píxel horizontal del canvas, calcula el valor matemático correspondiente, lo transforma a coordenadas de píxeles y dibuja la línea resultante. Maneja casos especiales como discontinuidades o asíntotas para evitar líneas erráticas en la gráfica.
