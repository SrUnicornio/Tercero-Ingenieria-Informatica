    Class ShapeForm

    Classdesc

    Manages the form inputs for shape parameters and provides a method to retrieve their values.

    This class interacts with the DOM to access the input fields for shape parameters such as type, coordinates, rotation, and color. It provides a method to gather the current values from these input fields and return them in a structured format for use in shape creation and rendering.
