Interface AxisConfig

AxisConfig

Description

Parámetros visuales y de escala compartidos por ambos ejes y por el renderizador de cuadrícula.

El único parámetro lógico configurable por el usuario es tickSpacingMeters. El resto son parámetros estéticos.
