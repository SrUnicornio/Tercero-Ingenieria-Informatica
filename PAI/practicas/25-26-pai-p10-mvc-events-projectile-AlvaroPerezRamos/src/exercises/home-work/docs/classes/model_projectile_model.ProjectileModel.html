Class ProjectileModel

ProjectileModel

Classdesc

Modelo de la simulación de tiro parabólico. Calcula la física y notifica a los observadores al finalizar. Mantiene el historial de trayectorias para soporte de reescalado.

Patrones aplicados:

  • Observer: notifica el aterrizaje sin acoplar modelo y controlador.

Example

const model = new ProjectileModel();
model.addObserver(controller);
model.launch({
  initialSpeed: 50,
  angleDegrees: 45,
  initialHeight: 10,
  gravity: 9.81,
});
const state = model.step(0.016);
