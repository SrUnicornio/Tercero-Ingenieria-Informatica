Class CoordinateSystem

CoordinateSystem

Classdesc

Fachada que agrupa la cuadrícula y los dos ejes cartesianos.

Se construye una vez en ProjectileView y se actualiza con updateTransformer() cuando la escala cambia tras un nuevo lanzamiento.
