    Class ControlsPanel

    ControlsPanel

    Classdesc

    Fachada del panel de controles. Proporciona una interfaz unificada para la interacción con LissajousView dentro del patrón MVC. Gestiona directamente el checkbox de animación de fase (toggle), cuyo tipo es diferente al de los controles numéricos delegados.
