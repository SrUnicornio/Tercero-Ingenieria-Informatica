Class CannonDrawer

CannonDrawer

Classdesc

Renderiza el cañón en el punto de lanzamiento con el ángulo y el color del lanzamiento activo.

Example

const cannon = new CannonDrawer(context, transformer);
cannon.draw(0, 45, 'steelblue');
