Class CoordinateTransformer

CoordinateTransformer

Classdesc

Gestiona la transformación afín entre metros y píxeles. Es el único lugar donde se realizan estos cálculos (DRY).

El eje Y del canvas está invertido respecto al matemático: en canvas, Y crece hacia abajo; en física, hacia arriba.

Example

const transformer = new CoordinateTransformer(config);
const { x, y } = transformer.toPixel(50, 30);
